# 原型使用说明

本目录中的原型以当前 `src/` 实现为事实基准，用于展示和验收现有界面，不作为要求项目代码反向适配的上游设计稿。

## 文件对应关系

- `core-flow.html`：首页、答题、答对/答错反馈、报告、学习记录、个人中心。
- `components.html`：当前代码实际使用的输入、按钮、选项、反馈、记录、资料和系统提示状态。
- `extended.html`：首页文本/链接/文件模式、系统 Loading/Modal、继续闯关、报告重新生成状态。
- `current-ui.css`：从当前项目 SCSS 提取的原型共用样式。

## 同步规则

1. 项目功能或 UI 已经确认变更后，再同步这里的原型。
2. 原型不得虚构项目中不存在的页面、路由或交互。
3. 首页输入是内联状态；加载与错误使用系统提示；分享使用微信系统分享能力。
4. 答题页保持两行顶部信息、可滚动内容区和非 fixed 底部操作区。
5. 若原型与项目不一致，以当前项目代码和实际运行界面为准。
