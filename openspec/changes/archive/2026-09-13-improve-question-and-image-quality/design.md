## Context

四个独立问题需要解决。核心改动在 prompt 优化和图片生成流程。

## Decisions

### Decision 1: 增强题目生成 prompt

**选择**: 在 system prompt 中增加意图理解和难度控制规则

**理由**: prompt 是最直接的优化方式

### Decision 2: 图片决策迁移到生成阶段

**选择**: 在题目生成 schema 中新增 `needs_image` 和 `image_prompt` 字段，让 LLM 在生成题目时就决定是否需要图片和图片描述

**理由**:
- 一次 LLM 调用完成题目生成+图片决策，减少延迟
- LLM 理解题目语义，决策更准确
- 图片 prompt 由 LLM 生成，比程序拼接更精准

### Decision 3: 图片尺寸增大+点击放大

**选择**: 图片高度从320px增加到480px，添加点击放大功能

**理由**: 提升图片可读性

### Decision 4: 避免图片细节题

**选择**: 在 prompt 中明确要求"不要出需要仔细辨认图片细节的题目"

**理由**: AI 生成的图片细节不一定准确，依赖细节出题会降低体验
