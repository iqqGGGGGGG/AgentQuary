# TabBar icon sources

The source shapes are from the [Lucide icon set](https://lucide.dev/) under the ISC License:

- `home.svg`: `house`
- `history.svg`: `notebook-tabs`
- `profile.svg`: `user-round`

The PNG files are generated at 81 x 81 with transparent backgrounds by `scripts/render-tab-icons.ps1`.

- Default color: `#8B7FA3`
- Selected color: `#7C5CFC`
