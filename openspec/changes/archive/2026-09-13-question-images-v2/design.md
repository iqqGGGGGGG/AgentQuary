## Context

项目需要为题目配图。使用 Unsplash 免费图库 + 腾讯云 COS 存储，替代昂贵的 AI 图片生成。

## Decisions

### Decision 1: 图片来源 — Unsplash 免费图库

**选择**: Unsplash API 搜索免费图片

**理由**:
- 免费，无生成费用
- 搜索速度快（<1秒）
- 真实照片质量高，适合学习场景
- Unsplash License 允许免费商用

### Decision 2: 图片存储 — 腾讯云 COS

**选择**: 上传到腾讯云 COS `gqq-agent-1310553153` 存储桶

**理由**:
- 用户已有 COS 存储桶
- CDN 加速，访问快
- 图片永久存储

### Decision 3: 关键词提取 — LLM 从题目提取英文搜索词

**选择**: 用 LLM 从题目中提取 1-2 个英文关键词用于搜索

**理由**:
- Unsplash 英文搜索效果最好
- LLM 理解题目语义，提取精准关键词

### Decision 4: 异步并行搜索

**选择**: 所有题目的图片搜索并行执行

**理由**:
- 减少总耗时
- 单题失败不影响其他题

## Risks / Trade-offs

**[Unsplash 搜索质量]** → 某些抽象概念可能搜不到好图。缓解：搜索失败时不显示图片。

**[COS 上传延迟]** → 每张图片需要上传时间。缓解：并行上传。
