## Context

项目已使用阿里云百炼 Embedding API，百炼也提供图片生成模型（qwen-image-3.0-pro）。需要集成百炼图片生成 API，在题目生成后为每道题生成配图。

## Goals / Non-Goals

**Goals:**
- 用户可选启用图片生成
- 根据题目内容生成相关配图
- 图片本地存储，通过 API 访问
- 答题页和历史记录展示图片

**Non-Goals:**
- 不实现图片编辑/滤镜
- 不实现图片缓存策略
- 不支持用户上传自定义图片

## Decisions

### Decision 1: 图片生成 API — 阿里云百炼 qwen-image-3.0-pro

**选择**: 使用百炼 `qwen-image-3.0-pro` 模型

**理由**:
- 项目已集成百炼 Embedding，复用同一平台
- 中文理解好，生成质量高
- 通过 OpenAI 兼容 API 调用

### Decision 2: 图片生成时机 — 题目生成后批量生成

**选择**: 在 `chain_generate` 返回题目后，为每道题异步生成图片

**理由**:
- 不阻塞题目生成主流程
- 可并行生成多张图片
- 图片生成失败不影响题目

### Decision 3: 图片存储 — 本地文件系统

**选择**: `server/uploads/images/{session_id}_{question_id}.png`

**理由**:
- 复用现有 uploads 目录
- 简单可靠

### Decision 4: Prompt 策略 — 从题目提取关键词生成图片

**选择**: 使用 LLM 从题目中提取图片描述关键词，然后调用图片生成

**理由**:
- 题目文字不适合直接作为图片 prompt
- 提取关键词后生成的图片更精准

## Risks / Trade-offs

**[图片生成延迟]** → 每张图片需要 5-15 秒。缓解：并行生成，前端显示 loading。

**[图片生成费用]** → 百炼图片生成按次计费。缓解：用户可选启用，默认关闭。

**[图片质量不稳定]** → AI 生成的图片可能不符合预期。缓解：图片仅作为辅助，不影响答题核心体验。
