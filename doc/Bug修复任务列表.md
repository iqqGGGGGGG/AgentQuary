## 额外发现的问题与边界

1. **真机网络配置是上线前阻断项。** 当前前端默认 API 地址为 `http://127.0.0.1:8000`。真机中的 `127.0.0.1` 指向手机自身；上线或真机联调必须配置可访问的 HTTPS 服务地址并加入微信合法域名。该项需要实际部署域名，不能在 Bug 修复中猜测填写。
2. **头像文件当前保存在单机后端磁盘。** 本地/单实例环境可正常持久化；若使用多实例或无状态云部署，应迁移到对象存储，否则扩容或重建实例后头像可能丢失。
3. **题干完全相同已被硬性阻止，语义近似仍依赖模型判断。** 服务端会排除空白和大小写归一化后完全相同的题目，并在提示词中要求换知识点或考查角度；若要严格识别改写后的同义题，需要额外的语义相似度模型，这超出本次 Bug 修复边界。
4. **MiMo 全局变量已保存，但当前 Codex 进程不会热加载。** 重启 Codex 后 MiMo MCP 才能读取；本轮两次 MiMo 审查尝试分别受缺少进程环境变量和长时间无响应影响，没有获得可用审查结论。

## 建议的 5 分钟真机验收顺序

1. 在刘海屏与非刘海屏各打开答题页，确认退出、关卡文字、完整进度条均在安全区下方。
2. 用短题目确认页面不能拖出大段空白；用长题目确认中间内容可滚动且底部按钮始终可用。
3. 完成一关后点“再来一关”，确认出现生成等待态，并逐题核对题干不与上一关相同。
4. 在“我的”页选择微信头像、输入微信昵称并保存；重新进入页面确认资料仍存在。
5. 在开发者工具切换至少一个窄屏 Android、一个刘海 iPhone 和一个非刘海机型，确认无横向溢出与遮挡。
